Besoin d’aide pour les repas, le suivi ou tes activités ? Retrouve ici les réponses essentielles.

Se connecter

Utilise le bouton Apple, Google ou GitHub dans l’application. Pour retrouver tes données sur le même appareil, reconnecte-toi avec le même compte et le même service.

Retrouver mes données

Les repas, favoris, mesures, objectifs et séances sont conservés localement, séparément pour chaque compte. Ils ne sont pas synchronisés entre appareils par SteelFit. Une suppression de l’application ou des données de l’appareil peut les effacer.

Comprendre le scan

L’analyse est réalisée sur un iPhone compatible avec un modèle embarqué. Elle peut manquer ou confondre des aliments. Vérifie les propositions, complète les ingrédients et ajuste les quantités avant de calculer les apports. Les estimations ne remplacent pas une mesure des portions ni un avis professionnel.

Si le scan n’est pas disponible ou ne reconnaît pas le repas, utilise la sélection manuelle.

Rappels d’hydratation

Autorise les notifications dans les réglages de l’iPhone, puis choisis tes rappels dans SteelFit. Ajoute les verres réellement consommés pour mettre ton suivi à jour.

Déconnexion et suppression

La déconnexion ferme la session et conserve le suivi sur cet appareil. Pour supprimer ton compte, ouvre Profil, puis « Supprimer mon compte » et confirme. La suppression du compte SteelFit ne supprime pas ton compte Apple, Google ou GitHub.

Contacter l’assistance

Signale un problème sur notre page d’assistance GitHub. Décris l’écran concerné et ta version d’iOS. Ne publie pas de mot de passe, de photo personnelle ou de données de santé dans un signalement public.
